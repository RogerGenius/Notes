## Android 笔记撰写规则

1. **章节号跨度 5**（01、05、10…），新模块只占自己的号，已有章节编号不动；章内小节用「章号.序号」。
2. **正文只写已整理内容**，未整理的模块只在笔记开头的「课程地图」表里标状态，不建空标题。
3. **涉及前后端代码时，前后端都要列出**，并按代码语言分开放进不同代码块（Java / XML / SQL / JavaScript 等各自独立成块，不混写）。
4. **代码不需要全部列出**，只写：
   - `import` 导入
   - 类结构（继承关系、注解）
   - 相关成员变量
   - 相关方法（方法体内只保留与知识点有关的代码，其余用 `// ......` 代替）
5. 示例代码统一使用 **Java**（除非该知识点本身就是 Kotlin 专属）。
