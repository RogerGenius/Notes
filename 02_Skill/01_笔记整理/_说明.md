# Skill 目录说明

本目录存放供 AI 执行的 skill（可复用的作业流程），与知识笔记分开管理。

## 目录结构

```
02_Skill/
├── _说明.md
└── 01_笔记整理/
    └── 整理笔记/
        ├── SKILL.md      # 触发条件 + 完整作业流程
        └── evals/        # 测试用例（可选）
```

## 子目录规划

- **一级子目录按能力领域划分**：`01_笔记整理`（现有）；未来若有「代码审查」「资料收集」等独立能力，再新建 `02_xxx`、`03_xxx`。
- **二级目录即 skill 名**：目录名与 `SKILL.md` 的 `name` 字段一致，便于被工具直接发现。
- 每个 skill 目录自包含：`SKILL.md` 必须存在；可附带 `scripts/`（确定性脚本）、`references/`（按需加载的长文档）、`assets/`（模板）。

## 规则

- `SKILL.md` 的 YAML 头必填 `name` 与 `description`，触发场景全部写在 `description` 里。
- 正文控制在 500 行以内；超长内容放 `references/` 并在正文里给指针。
- skill 执行结果若会改动知识库，必须在 `SKILL.md` 中写明遵循 `01_知识库规范/`。
