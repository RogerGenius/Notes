# 服务端基础设施与中间件

## 用途
承载应用的「运行时设施」笔记，偏运维向。

## 归属
- Web 服务器与网关：Nginx 等
- 注册配置中心：Nacos、Zookeeper、Consul 等
- 容器与编排：Docker、K8s 等
- 消息队列：Kafka、RabbitMQ、RocketMQ 等
- 持续集成部署、监控与日志

## 边界
- 业务代码不在此（Spring 业务逻辑 → 15_Web开发）
- 系统本身怎么用（Linux 命令）→ 40_操作系统与软件使用
- 云厂商的具体产品 SDK → 50_第三方服务与厂商
